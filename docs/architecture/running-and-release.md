# التشغيل والإصدار

> نُقل هذا الملف حرفياً من CLAUDE.md (2026-10-28) ليبقى CLAUDE.md فهرساً قصيراً. المرجع الحاكم للقرارات: docs/adr/.

## Running
- API: `dotnet run --project API` → https://localhost:7181 (Swagger at `/swagger`), http://localhost:5204. **Configuration (2026-10-10):** `StartupSettings.EnsureValid` stops startup with an Arabic list of what is missing (connection string, `JwtSettings:Key` ≥ 32 chars, `DeviceInventory:PasswordKey` = 32-byte Base64). CORS origins = `Cors:AllowedOrigins`, Swagger = `Swagger:Enabled` (both set in `appsettings.Development.json`; production defaults: no origins, Swagger off), `Database:MigrateOnStartup` (default true), health check `GET /health` (`DatabaseHealthCheck`). Production setup, keys, first admin and backups: `docs/DEPLOYMENT.md`. **Release (Linux):** `deploy/build-release.ps1` (output in gitignored `release/`). **Default = two packages for the server's actual layout** (user decision 2026-10-11: the server runs the API in `/var/www/dmc/EWMS-App` via the `ewms-api` service (`dotnet API.dll`, port 5000) and the UI in `.../angular` served by Nginx): `EWMS-<v>-api-linux-x64.tar.gz` (framework-dependent publish **without `appsettings.json`**, so the server's settings/keys are never overwritten; `appsettings.template.json` for reference) and `EWMS-<v>-web.tar.gz` (UI files). Update steps (backend first, then UI; backup DB + folder) in `docs/DEPLOYMENT.md` section A. `-Single` builds the v1.0.0-style single package: self-contained API + the Angular build in `wwwroot` + `deploy/appsettings.release.json` (no secrets) + `deploy/linux/` (systemd `ewms.service` with `TZ=Asia/Damascus` — the code uses local dates —, `nginx-ewms.conf` with WebSocket for `/hubs`, `ewms.env.example`). The API serves the SPA itself when `wwwroot/index.html` exists (`MapFallbackToFile` for every non-file path except `api/`, `hubs/`, `health`, `swagger`; index.html no-cache) — no CORS in production; `UseForwardedHeaders` trusts the local Nginx. Version = `<Version>` in `API/API.csproj` (+ `package.json` in the UI).
- Client: `cd F:\-EWMS-UI-main-main && npm start` (restart it after any `proxy.conf.json` change) → http://localhost:4200; `proxy.conf.json` proxies `/api` to https://localhost:7181. CORS policy `AllowAngular` in `Program.cs`.
