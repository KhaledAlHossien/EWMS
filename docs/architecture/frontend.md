# الواجهة (Angular)

> الربط مع الـ API، بنية الواجهة، الهوية البصرية، الترقيم والصفحات المشتركة.
> نُقل هذا الملف حرفياً من CLAUDE.md (2026-10-28) ليبقى CLAUDE.md فهرساً قصيراً. المرجع الحاكم للقرارات: docs/adr/.

## Frontend ↔ backend wiring (2026-09-27)
- `GET api/Auth/Me` (plain `[Authorize]`, `Users/Queries/GetMe`) returns the caller's `UserResponseDto` — used by the UI profile page.
- `ExceptionMiddleware`: `UnauthorizedAccessException` → **403 when the caller is authenticated**, 401 otherwise. 4xx messages are always shown (they are the Arabic business messages); only 500 details are hidden outside Development (fixed 2026-09-29 — before, production replaced every message with a generic one). The UI's JWT interceptor logs out on 401, so a business "not allowed" must never come back as 401.
- `Branches/GetAll` requires `ViewBranches` (loosening it was declined). The UI's `EwmsService.getBranchLookup()` derives the branch dropdown from `Department/GetAll` for users without that permission — keep that in mind before changing either endpoint.
- UI layout (2026-09-29): a sticky **top navbar** (`main-layout.html` `.topbar`, height `--topbar-h: 64px`) holds the notifications bell + unread badge, the profile link (avatar + name + role → `/profile`) and logout; these are **no longer in the sidebar**.
- **UI structure (review 2026-09-29):**
  - Routes are **lazy** (`loadComponent` in each feature's `<f>.routes.ts`, gathered by `app.routes.ts`); background preloading only of pages the user's permissions allow (`PermissionPreloadStrategy`) — initial bundle **≈ 412 KB** (budget 430/480 KB; 2026-10-14 slimming: icon sprite, logo as CSS mask, `@defer (on idle)` for the appearance menu and notification toasts in `main-layout.html`; Angular itself is ≈ 355 KB of it — measure with `ng build --stats-json` before adding big things). New page = a `loadComponent` route, never an eager import. OnPush is Angular 22's default: state shown in a template that changes after a request must be a signal.
  - **Helper lists never hide the main list (fix 2026-10-13):** a branch head with «عرض المستخدمين» but without «عرض الأدوار» saw an empty users page with no message. The page loaded the users together with the roles/departments/offices lists in one `forkJoin`, the refused roles list failed it all, and the page did not show load errors. Now:
    - Helper lists go through `orEmpty()` (`core/http/or-empty.ts`): a failed one becomes `[]` and the form says which list is missing.
    - In edit mode the record's current role/branch/department/office stays as the only option, so its value is shown and kept.
    - The users, branches, departments, offices and roles pages render `crud.loadError()` with «إعادة المحاولة», and the empty state hides while an error is shown.
    - Apply the same to any new page that combines its list with lookups.
  - **Admin list pages use `CrudPage`** (`shared/ui/crud-page.ts`, since 2026-10-10): add/edit in a dialog, the server error shown inside the dialog, silent reload of the list only after save, delete = confirm + local removal + row busy indicator; row buttons via `<app-row-actions>`. Use `[appSelectValue]`, never `[value]`, on a `<select>` bound to a signal (it showed the wrong option when options arrived late).
  - Role/permission names come from `core/constants/access.ts` (`AppRole`, `AppPermission`, `LEADER_ROLES` — mirror of the backend names). `AuthService` exposes `role`, `isSuperAdmin`, `isLeader`, `canReviewVacations` signals and typed `hasPermission()` / `hasRole()`.
  - Shared UI in `shared/ui/` — use these, don't re-implement per page: `app-modal` (backdrop, header, Esc, focus trap, first-field focus, scroll lock; stacked modals — only the top one reacts to Esc; `hasOpenModal()` for non-modal Esc listeners like the task drawer), `ConfirmService.ask(message, label)` → `Promise<boolean>` (host `app-confirm-host`), `ToastService` (`success/error/info`, `copy(text, label)`; host `app-toasts`) — both hosts are mounted once in `MainLayout`; `app-copy-text` for IPs/usernames (device passwords: `app-device-password` in `features/devices/device-ui.ts`, fetched on demand); `CrudPage` for the admin CRUD pages (`PageActions`/`ModalCrud`/`loader` were removed).
- **Visual identity & design (2026-09-29, user request: Syrian visual identity, Apple-inspired UI — layout unchanged, element design changed):**
  - Styles are split: `src/styles/_tokens.scss` (fonts, colors, themes, dark mode, map ramp) + `_base`, `_controls`, `_surfaces`, `_overlays`, `_utilities`; `styles.scss` only `@use`s them. **Components use tokens only — never raw colors** (every theme and dark mode depends on it). `--brand-600` = action/background (text on it: `--on-brand`), `--brand-700/800` = brand-colored text on tinted `--brand-50..300` (these are transparent mixes, so they work on light and dark), `--accent` = logo gold, `--fill`/`--fill-strong` = Apple gray fills (inputs, secondary buttons), `--material` + `--material-blur` = translucent bars.
  - Font: **Qomra Arabic** (`public/fonts/qomra-arabic-{light,regular,bold}.woff2`, weights 300/400/700; the `.otf` originals stay as fallback, `npm run fonts:woff2` regenerates the WOFF2 files).
  - **4 user-selectable palettes** from the identity guide — Forest (default), Golden Wheat, Charcoal, Deep Umber — each with light + dark: `ThemeService` sets `data-theme` + `data-mode` (no `data-mode` = follow the OS) on `<html>`, saved per browser (`localStorage` key `ewms_appearance`); `index.html` applies the saved value before Angular boots (keep its regex in sync with `PALETTES`). Picker = `features/layout/appearance-menu.ts` in the navbar.
  - Logo: `shared/ui/logo.ts` draws `public/brand/logo.svg` as a CSS mask filled with `currentColor` (→ `--accent`), with `print-color-adjust: exact` for the print pages (`logo-paths.ts` was removed 2026-10-14 to slim the initial bundle); favicon `public/brand/logo.svg`.
  - **Governorate stamps**: `public/stamps/{framed|plain}/SYxx.svg` (codes = geojson `code`), generated by `scripts/prepare-stamps.mjs "<identity SVG folder>"` (ink → `currentColor`, paper → `--stamp-paper`, per-file class prefixes, cropped viewBoxes). Rendered inline by `<app-stamp code variant>` (`shared/ui/stamp.ts`, cached `StampService`, `STAMP_LANDMARKS`). Used in the map (hover card = plain stamp; zoomed governorate = tilted framed stamp, `showStamp` input, off in the coordinate picker) and faintly on the login page. The Daraa framed stamp has live "SYRIA" text in a missing font (fallback serif) — ask the designer to re-export it with outlined text.
  - Layout: light translucent macOS-style sidebar (logo, sections "الإجازات"/"الإدارة", `shared/ui/icon.ts` icons), translucent navbar, Apple-ID-style login.
  - **Icons (2026-10-12, user decision): one unified set, no emoji.** `<app-icon name [size] [weight]>` (`shared/ui/icon.ts`, about 104 line icons on a 24×24 grid in SF Symbols style, drawn for the project; they take the text color, so they follow the palettes and dark mode). **Since 2026-10-14 the drawings live in one sprite `public/icons.svg`** (each icon is a `<use>`), out of the JavaScript bundle: the source is `scripts/icons/icon-paths.mjs`, and `npm run icons` regenerates the sprite plus `shared/ui/icon-names.ts` (names + a content-hash `?v=` so browsers fetch a changed sprite). Apple's real SF Symbols were requested, but their license only allows apps on Apple platforms, so they are not used. **Emoji and inline `<svg>` icons are gone from the templates** — including the Feather/Lucide paths that were copied into `row-actions`, `modal`, `toasts`, the admin pages and the login page. The only inline SVG left is the Syria map. `app-stat-tile` takes a required `icon` name. Icon keys stored as emoji (`WorkTask.Icon`, `ToDoList.Icon` ≤ 8 chars, the dashboard «آخر الإجراءات» icons from `DashboardService`) stay as data and are rendered through `iconFor(value, fallback)`; the pickers show the icons and save the same keys. The free-text custom symbol of a «مفكرتي» list was removed (a list with one shows the default icon). The printed vacation form keeps its paper symbols (✓ ❖ •). `public/favicon.ico` (unused Angular default) was deleted. Global CSS size rules (`.stat-icon`, `.icon-btn`, `.modal-close`, `.toast-icon`, `.confirm-icon`…) target `app-icon` too.
  - **Date fields (fix 2026-10-13):** on Arabic pages Chrome drew the empty date placeholder reversed («ةنس/رهش/موي»). One rule in `styles/_controls.scss` (`unicode-bidi: normal` on the `::-webkit-datetime-edit-*-field` parts) fixes every date field; CSS `direction` changes do not.
  - Sidebar links are data (`sections` computed in `main-layout.ts`, filtered by permission) — add a page there, not in the template. Sections collapse (animated `grid-template-rows` 0fr↔1fr; a collapsed section containing the current page shows a dot), and the whole sidebar collapses to icons only (`.shell.collapsed`, 72px, hover tooltip from `data-label`; the sidebar has `z-index: 60` so tooltips aren't clipped by page cards). Both states persist in `localStorage` key `ewms_sidebar`. **Collapsed rail (2026-10-13, user decisions):** every titled section is one icon button (`NavSection.icon`: `checklist` المهام, `suitcase`, `toolbox`, `placeGround`, `serverRack`, `folderChart`, `orgChart`, with a small ⌄) whose pages drop down beneath it in a tray (`main-layout-rail.scss`); one section open at a time (`railOpen`, saved as `rail` in `ewms_sidebar`, so the last opened one stays open); a closed section holding the current page shows a dot. The task pages (لوحة المهام, مفكرتي, recurring, stats) form the section «المهام»; only لوحة المتابعة stays untitled at the top. **Motion** (`main-layout-motion.scss`, all off under `prefers-reduced-motion`): one `.nav-indicator` background slides to the active link (`placeIndicator`/`followIndicator` in `main-layout.ts`, hidden when its section is closed and below 860px), collapse = labels fade first then `settling` fades the rail in, expand = labels appear staggered, opening a section staggers its links (`--i`), icons react to hover/press and a section icon pops when opened. **Below 860px (2026-10-12, user request):** the sidebar becomes a slim bar (logo + «القائمة» button, `compact`/`menuOpen` signals; `COMPACT_QUERY` must match the `@media` in `main-layout-compact.scss`, a separate file so each stylesheet stays under the 8 kB component budget); the links are closed until the button is pressed, then shown as a uniform grid of equal buttons (3 columns, 2 below 560px; `.nav-group`/`.nav-group-inner` are `display: contents`) with the section titles as plain headings (`.nav-heading`); it closes on navigation and on Esc (unless a modal is open); the open state is not saved. The desktop collapse toggle is hidden there.
- UI: review page/nav gated on the `ApproveVacation` permission (not role names); notifications page + unread badge polling `UnreadCount` every 30s; the «إجازاتي» page handles the one-item create response and cancel; Projects UI removed.


## Pagination, truncated text, notifications page, request signature (2026-10-08, user decisions)
- **Pagination everywhere:** shared `app-pager` (`shared/ui/pager.ts`: «عرض 1–10 من N», السابق/التالي + numbers with …, page-size select, hides itself when one page is enough; `maintenance-ui.ts` re-exports it) + `Pagination<T>` (`core/utils/pagination.ts`) for **client-side** lists (`pager = new Pagination(() => this.filtered())`, `pager.items()` in the `@for`, page auto-clamps when the list shrinks, size choice saved in `localStorage ewms_page_size`, optional `urlKey` for `?page=`). Applied to users, branches, departments, offices, roles, vacation types/holidays/review (team table + pending cards)/«إجازاتي» history, work tasks, device catalog/sites/site installations, maintenance settings/my requests, and the «مفكرتي» lists grid (12 per page). **Server-paged** pages (maintenance requests table, devices, installations, spare parts, tasks, histories) use the same component with `[sizes]="[]"` (fixed size). New list page = add a `Pagination` + `<app-pager>`, never an unbounded table.
- **Maintenance board columns** page per status, 5 cards each (`BOARD_LIMIT`), mini pager under each column (`columnTo`); after a drag both columns reload.
- **Full text on hover:** `TruncationTipService` (started in `MainLayout`) listens globally; any element with `text-overflow: ellipsis` or `-webkit-line-clamp` that is actually clipped shows its full text in a tooltip on hover/focus (also the clipped children of small cards). Elements with a `title` are skipped. No per-page markup needed — keep using ellipsis/line-clamp CSS.
- **Notifications page** redesigned (cards grouped اليوم/أمس/أقدم, type icon, relative time, unread dot, pills الكل/غير المقروءة) with **server paging**: `GET api/Notifications/Page?unreadOnly&page&pageSize` (→ `PagedResultDto`, ≤ 100) — the bell and toasts still use `My`/`UnreadCount`.
- **Roles search** shows a suggestions dropdown under the box (keyboard: ↑↓ Enter Esc): roles whose **name** matches; only if none does, roles that hold a matching permission (name or Arabic description). The table shows exactly the same matches; picking one shows that role alone.
- **Maintenance request form:** typing a serial shows matching devices (`MaintenanceDevices/GetAll?serialNumber=prefix&pageSize=6`, debounced); the «بحث» button/Enter still does the exact `BySerial` lookup and the «add device» offer. Client lookup unchanged.
- **Vacation print — requester signature:** `Vacation.RequestSignatureId` (FK Restrict, set from the employee's **current** signature version at submission, like the decision signatures); `VacationPrintDto.RequesterSignature` fills the «توقيع مقدم الطلب» box. Vacations submitted before the migration (or by someone with no signature) print an **empty** box, by decision.
