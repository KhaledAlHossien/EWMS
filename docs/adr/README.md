# سجلّ القرارات المعمارية (ADR)

كل ملف هنا يوثّق قراراً واحداً: **لماذا** اتُّخذ، ما البدائل، وما نتائجه. الكود يقول *ماذا*، وهذا المجلد يقول *لماذا*.
التفاصيل التشغيلية لكل وحدة في [`docs/architecture/`](../architecture/README.md).

## القواعد

- لا يُعدَّل قرار قبل أن يُراجَع: إن تغيّر الرأي نكتب ADR جديداً حالته «مُقرّ» ونضع على القديم «حلّ محلّه ADR-NNNN».
- أي قرار يمسّ الصلاحيات أو البيانات أو الأمان أو شكل الطبقات يحتاج ADR قبل الدمج.
- القالب: [`0000-template.md`](0000-template.md). الحالات: مُقرّ، مُقترَح، مرفوض، حلّ محلّه غيره.
